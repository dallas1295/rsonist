# rsonist

A small, zero-dependency JSON library for Rust.

`rsonist` parses JSON text into a [`Value`], lets you navigate and extract
typed primitives from it, and serializes a [`Value`] back to JSON — without
pulling in `serde` or any external crate.

- **No dependencies.** the main insipration for this project was to have a bloat and serde free implementation for basic JSON parsing and building.
- **Parse & build.** `to_value`/`to_values` for parsing; [`JSONBuilder`] or the
  `rson!` macro for constructing values.
- **Typed access.** `get` / `get_from` to drill in, `as_*` methods to read
  primitives.
- **Serialize.** `to_str` for compact output, `prettify` for pretty-printed.

## Installation
### From Crates.io
```
cargo add rsonist
```

### From Source:
Add it to your `Cargo.toml`:

```toml
[dependencies]
rsonist = "0.2.1"
```

## Quick start

Parse a document, navigate it, and pull out values:

```rust
use rsonist::to_value;

let json = r#"{"name": "alice", "scores": [10, 20, 30]}"#;
let root = to_value(json)?;

let name = root.get("name").unwrap().as_str().unwrap();
let first = root.get("scores").unwrap().get_from(0).unwrap().as_i64().unwrap();

assert_eq!(name, "alice");
assert_eq!(first, 10);
# Ok::<(), rsonist::ScanError>(())
```

## Parsing

| Function     | Description |
| ------------ | ----------- |
| `to_value`   | Parses a single JSON document into a [`Value`]. Errors on trailing data. |
| `to_values`  | Parses multiple whitespace-separated JSON documents into a `Vec<Value>`. |

Errors come back as [`ScanError`], each carrying a byte position.

## Building

Build objects incrementally with [`JSONBuilder`] (keys are stored in a
`BTreeMap`, so serialized output is always in sorted, deterministic order):

```rust
use rsonist::JSONBuilder;

let mut builder = JSONBuilder::new();
builder.add_pair("name", "alice".to_string());
builder.add_pair("age", 30);
builder.add_object("meta", |c| {
    c.add_pair("active", true);
});

let json = builder.build_val().to_str();
// {"age": 30, "meta": {"active": true}, "name": "alice"}
```

Or with the `rson!` macro, using JSON-like literal syntax:

```rust
use rsonist::rson;

let v = rson!({
    "name": "alice",
    "age": 30,
    "active": true,
    "scores": rson!([10, 20, 30]),
});
```

Common Rust types implement `Into<Value>`, so integers, floats, booleans,
`String`/`&str`, `Vec<T>`, and `BTreeMap<String, T>` all convert directly.

## Accessing values

- **Navigate:** `get(key)` for objects, `get_from(index)` for arrays. Both
  return `Option<&Value>` and chain freely.
- **Extract:** `as_str`, `as_bool`, `as_i64`, `as_u64`, `as_f64`. Numeric
  conversions widen where they fit (e.g. `as_i64` on a `UInt`, `as_f64` on any
  number).
- **Borrow:** `as_obj` and `as_array` return the inner map/slice directly — no
  allocation.

## Serializing

```rust
use rsonist::JSONBuilder;

let json = JSONBuilder::new()
    .add_pair("name", "alice".to_string())
    .build_val()
    .to_str();        // compact:  {"name": "alice"}

let pretty = JSONBuilder::new()
    .add_pair("name", "alice".to_string())
    .build_val()
    .prettify();      // indented, multi-line
```

Non-finite floats (`NaN`, `inf`) serialize as `null`.

## API

| Type            | Description |
| --------------- | ----------- |
| `Value`         | Any JSON value — the central type. Maps one-to-one onto JSON data types. |
| `JsonNumber`    | A number, distinguishing `UInt`, `Int`, and `Float`. |
| `JSONBuilder`   | Assembles JSON objects incrementally. |
| `to_value`      | Parse a single JSON document. |
| `to_values`     | Parse multiple JSON documents. |
| `ScanError`     | Error returned on malformed input, with a byte position. |
| `rson!`         | Macro for JSON-like value literals. |
| `obj_from_pair` | Filter a slice of objects by a key/value match. |
